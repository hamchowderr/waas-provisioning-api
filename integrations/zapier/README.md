# AnyPress for Zapier

The [AnyPress](https://anypress.io) app for Zapier.

| | |
|---|---|
| Trigger | **Site Event**: a site is ready, failed, updated, suspended, resumed, deleted, restored, rolled back or backed up. A REST hook: the Zap registers its own webhook with AnyPress when it is turned on, and every request's signature is checked |
| Actions | **Create Site**, **Suspend Site**, **Resume Site**, **Delete Site** |
| Search | **Find Site**, by your reference or its site ID |

Connect with an API key and secret from [app.anypress.io](https://app.anypress.io) (API keys). A partner key works on every storefront in a reseller account; pick the storefront on each step.

Help: [AnyPress docs](https://shop.anypress.io/docs-category/automation/) and support@anypress.io.
