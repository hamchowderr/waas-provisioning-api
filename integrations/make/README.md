# AnyPress

Create and manage WordPress sites on [AnyPress](https://anypress.io) from Make, and start a scenario when a site is ready.

- **Watch Site Events**: starts when a site is ready, fails, is suspended, resumed, deleted and more.
- **Create a Site**, **Get a Site**, **Suspend a Site**, **Resume a Site**, **Delete a Site**.

Connect with an API key and secret from app.anypress.io (API keys). Resellers with a partner key add one connection per storefront, with that storefront's ID.

Help: https://shop.anypress.io/docs-category/automation/ or support@anypress.io.
